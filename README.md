# self-service-s-ra-rahatlatma-
Sırala, kafelerde kasa önündeki kuyruğu bitiren bir QR sipariş sistemi. Müşteri masadaki QR kodu okutur, siparişini seçer ve sıra numarası alır. Oturduğu yerden sırasını telefonundan takip eder, sırası yaklaşınca uyarı gelir. Kasaya geldiğinde siparişi ekranda hazırdır, sadece öder. Uygulama indirmek gerekmez, kuyrukta ayakta beklemek biter.
